# Prisma Landing Page

React 18, Vite, TypeScript, Tailwind CSS 3, Framer Motion, Lucide React로 구현한 3개 섹션(Hero, About, Features) 랜딩 페이지입니다.

## 실행

```bash
npm install
npm run dev
```

## 검증·빌드

```bash
npm run typecheck
npm run build
npm run preview
```

영상과 기능 카드 이미지는 제공된 Higgsfield·CloudFront URL을 사용하므로 화면 확인 시 인터넷 연결이 필요합니다.
